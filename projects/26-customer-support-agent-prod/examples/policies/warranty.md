# Warranty and returns

## Manufacturer warranty
Electronics carry a 12 month manufacturer warranty against defects. Warranty claims are handled by
exchange or repair, not by refund.

## How to return an item
To return an item, start a refund request with your order number. We email a prepaid return label.
Pack the item in its original packaging where possible.

## Damaged on arrival
If an item arrives damaged, send a photo to support within 7 days of delivery and we will replace it
at no cost.
