# Security Policy

## Passwords and keys
Never paste API keys, passwords or customer data into chat tools or tickets. Rotate any key that was exposed within 24 hours.

## Laptops
Report a lost or stolen laptop to the security team within 1 hour. Full-disk encryption is mandatory on all company laptops.

## Phishing
Forward suspicious emails to the security mailbox and do not click links. The security team answers within 4 business hours.
